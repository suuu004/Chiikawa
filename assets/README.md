# 캐릭터 리소스

걷는 애니메이션 GIF 파일을 이 폴더에 넣습니다.

- GIF 하나만 쓸 때: `usagi-walk.gif`
- GIF를 순서대로 재생할 때: `usagi-01.gif`, `usagi-02.gif`, `usagi-03.gif`처럼 번호를 붙입니다.

번호가 붙은 GIF가 있으면 숫자 순으로 각 3초씩 재생하고 다시 반복합니다. 번호 파일이 없으면 `usagi-walk.gif`를 사용합니다. 재생 시간은 `renderer.js`의 `gifDurationMs` 값으로 바꿀 수 있습니다. 파일을 추가하거나 이름을 바꾼 뒤 앱을 다시 실행하세요.

권장 사항:

- 배경이 투명한 애니메이션 GIF
- 한 방향을 보고 제자리에서 걷는 루프 애니메이션
- 프레임마다 캔버스 크기와 캐릭터 위치가 일정한 파일
- 캐릭터 바깥 여백이 너무 크지 않은 파일

앱이 화면 위를 이동시키고 좌우 방향을 뒤집으므로, 리소스 자체는 한쪽 방향만 있어도 됩니다. GIF 파일이 없으면 기본 SVG 캐릭터가 계속 표시됩니다.

투명도가 더 부드러운 정지 그림은 PNG로 보관할 수 있지만, PNG 한 장에는 애니메이션이 들어 있지 않습니다. 여러 PNG 프레임이나 스프라이트 시트를 구했다면 그 형식에 맞게 코드 연결이 추가로 필요합니다.
